# Security

Do not report security vulnerabilities through public GitHub issues.

Contact [Supermetrics support](https://docs.supermetrics.com/) or email dev-rnd@supermetrics.com and identify the report as a security issue. Include the affected client or endpoint, reproduction steps, and potential impact. Avoid including credentials, access tokens, or customer data.

For information about Supermetrics' security and data-handling practices, see the [Supermetrics privacy policy](https://supermetrics.com/privacy-policy) and [terms of service](https://supermetrics.com/terms-of-service).
